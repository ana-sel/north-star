## Frozen Content Contract for Implementation AI

**Status:** V1 PRODUCT DECISION — FROZEN  
**Audience:** Coding AI / implementation agent  
**Purpose:** Implement the agreed Compass V1 content model without needing access to prior product discussions.

---

# 0. READ THIS FIRST

This document defines the **V1 content scope and behavioural rules** for:

1. Foundations
2. Growth Paths
3. Daily Habits
4. Path practices / returns
5. ownership / deduplication rules
6. how these appear on Today, Paths and Habits screens

Do **not** reinterpret, expand, merge or replace this set without an explicit product decision.

The most important mental model is:

> **Foundations teach me how to function.**  
> **Habits make the daily floor automatic.**  
> **Growth Paths shape the qualities I deliberately practise.**  
> **Plan builds the actual life.**  
> **Today shows only the small useful intersection of those systems.**

Compass must not become:
- a giant checklist
- a streak-punishment app
- a therapy or medical app
- a daily morality score
- a limerence tracker
- a habit duplicate of the Paths system

---

# 1. V1 PRODUCT INTENT

Compass V1 should help a person:

- stabilise the basics of daily life
- regulate attention and reactions
- see reality more clearly
- stay themselves around people they idealise or want approval from
- reduce compulsive attachment / limerence patterns without centring the whole app on limerence
- build reciprocal, warm and dignified relationships
- build a larger, interesting, self-directed life
- create, ship, explore and play
- make progress without shame when days are missed

For the primary private tester, **limerence recovery is a major priority**, but the public app must remain broadly useful and must not present itself as treatment for limerence or any mental-health condition.

Use language such as:
- "practice"
- "return"
- "notice"
- "try"
- "may help"
- "what counts today"

Avoid:
- "cure"
- "treat"
- "heal your disorder"
- "fix your nervous system"
- diagnosis
- guaranteed psychological outcomes

# 2. THE FOUR SYSTEMS

## 2.1 Foundations

**Foundations = the floor.**

They are basic adult capacities that support life across all domains.

V1 includes **all 13 Foundations**.

A Foundation:
- may have practices
- may suggest one or more daily Habit templates
- may become Today's theme
- may use the same 3-stage journey machinery as Growth Paths
- must not become a diagnostic score
- must not duplicate a Growth Path when a basic skill already owns the behaviour

Foundations are not the same as Growth Paths.

---

## 2.2 Daily Habits

**Habit = something the user genuinely intends to do every day.**

If an action is:
- weekly
- 2–4 times per week
- situational
- "when triggered"
- "when someone crosses a boundary"
- "when I feel rejected"
- "when I have something to ship"

then it is **not a Habit**.

It belongs to:
- a Path practice
- a Foundation practice
- Plan
- a training schedule
- or an optional reminder outside the Habits engine

Daily Habits may have streak/progress logic, but missed days must never produce shame language.

---

## 2.3 Growth Paths

**Growth Path = one quality the user deliberately practises becoming more able to embody.**

Examples:
- Non-attachment
- Quiet Authority
- Curiosity
- Agency

Growth Paths are not daily streaks.

A Path normally has:
- a short explanation
- "how it shows up"
- one current practice / return action
- what counts
- optional voice pair
- optional linked daily ritual only if the action is genuinely daily
- 3-stage progress model

A Path return is typically practised **2–4× per week or situationally**.

Never require the same Path every day.

---

## 2.4 Plan

Plan contains:
- actual tasks
- things being built
- practical actions

Examples:
- upload Compass beta
- call estate agent
- research a property
- publish product page

Do not convert practical tasks into Habits merely because they are important.

---

# 3. ACTIVE FOCUS RULE

The app may contain all V1 Foundations and all featured Growth Paths, but the user's **active journey focus is capped at 3 total**.

Recommended mental model:

- 1 primary focus
- up to 2 lighter supporting journeys

The cap applies across:
- active Foundations
- active Growth Paths

Daily Habits do **not** consume one of these 3 active journey slots.

Example:

Active journeys:
1. See Clearly — Foundation
2. Non-attachment — Growth Path
3. Agency — Growth Path

Daily Habits may still include:
- Water on waking
- Morning daylight
- SPF
- Wind-down

without requiring Tend the Body to be one of the 3 active journeys.

---

# 4. THREE-STAGE PATH / FOUNDATION MODEL

V1 uses the existing 3-stage model:

1. **Watching**
2. **Doing**
3. **Under pressure**

Frozen return thresholds:

- Watching closes at **3 returns**
- Doing closes at **9 total returns**
- Under pressure reflection opens at **15 total returns**

Important:

- the app may unlock the final reflection at 15 returns
- the app must **not auto-declare integration**
- "this feels like mine" / integrated state is **self-claimed**
- no one is told they "failed" a stage
- missed days do not erase progress
- Growth Paths are not represented as empty daily calendars

# 5. V1 FOUNDATIONS — ALL 13

## Tier 1 — The Ground

### F1. Tend the Body

**Purpose:** Support the physical floor required for everything else.

Owns:
- sleep basics
- daily movement baseline
- hydration routines
- hygiene / self-care routines
- personally chosen medication/supplement reminders
- morning light
- recovery / wind-down

Core Foundation practice:
> Notice one basic body need being neglected and meet it in the smallest useful way.

Daily Habit templates owned by this Foundation:
- Water on waking
- Morning daylight
- Take my medication / supplements
- Daily movement minimum
- Morning SPF — face + neck
- Evening oral care
- Wind-down / screen-free before sleep

Do not:
- prescribe supplements
- prescribe medication
- make medical claims
- tell users a product will make them youthful
- prescribe exercise intensity as medical advice

---

### F2. Regulate

**Purpose:** Build the capacity to notice activation and deliberately settle enough to choose the next action.

Core practice:
> Notice activation. Use one settling tool. Continue when you have enough space to choose.

Daily Habit template owned here:
- 5-minute meditation / settling

Possible Foundation tools:
- slow breathing
- orienting to surroundings
- grounding through senses
- brief stillness
- longer exhale
- unclenching / dropping shoulders

Do not claim these "reset the nervous system" or treat a condition.

---

### F3. Steady Your Attention

**Purpose:** Notice when attention has been captured and deliberately return it.

Core practice:
> Notice where attention went. Choose where to place it next. Return once.

Daily Habit template:
- First 15 minutes phone-free

Useful for:
- distraction
- rumination
- compulsive checking
- attention capture

Do not create a daily "didn't think about X" or "didn't check X" streak.

---

## Tier 2 — Inner World

### F4. Feel & Name

**Purpose:** Recognise emotional experience rather than immediately acting from it.

Core practice:
> Name the feeling as specifically as possible and identify what you may need.

What counts:
- user names one feeling
- optionally identifies one need
- no requirement to fix the feeling

No daily Habit required.

---

### F5. See Clearly

**Purpose:** Separate reality from interpretation, projection and uncertainty.

Core practice:
> Split the situation into Fact / Story / Unknown.

What counts:
- at least one factual observation
- at least one interpretation/story
- at least one unknown where relevant

Especially important for:
- idealisation
- assumptions
- relationship uncertainty
- catastrophising
- projection

No daily Habit required.

---

### F6. Self-relationship

**Purpose:** Treat oneself as a person worthy of care rather than using self-attack as motivation.

Core practice:
> Notice a harsh inner statement and answer it with a fairer, adult response.

What counts:
- harsh statement noticed
- fairer replacement written or spoken

No daily Habit required.

---

### F7. Know Yourself

**Purpose:** Distinguish personal values, wants, needs and identity from social approval or inherited expectations.

Core practice:
> Ask: "What do I actually want here if nobody is watching?"

What counts:
- user identifies one genuine preference/value/need

No daily Habit required.

---

## Tier 3 — Other People

### F8. Communicate

**Purpose:** Express needs, requests, limits and repair clearly.

Core practice:
> Say the need, request or no clearly and without unnecessary aggression or over-explaining.

Owns basic boundary **tools**.

This is why **Boundaries is not a featured V1 Growth Path**.

No daily Habit required.

---

### F9. Relate

**Purpose:** Stay connected to another person without abandoning oneself.

Core practice:
> Notice both sides: "What is happening for them?" and "What remains true for me?"

Owns:
- basic reciprocity awareness
- attachment awareness
- consent / mutuality principles
- connection skills

However, **Reciprocity remains a featured Growth Path** because it is a specific quality of not over-giving / chasing.

No daily Habit required.

---

## Tier 4 — Meeting Life

### F10. Handle Hard Things

**Purpose:** Stay with pain, grief, uncertainty or failure without immediately fleeing, numbing or forcing resolution.

Core practice:
> Let the difficult thing be true for a moment without arguing with it or demanding immediate relief.

What counts:
- user allows the experience
- no requirement to feel better

Distinct from Resilience:
- Handle Hard Things = staying with difficulty
- Resilience = returning to life and taking the next action after difficulty

No daily Habit required.

---

### F11. Keep Your Word

**Purpose:** Build reliability toward self and others.

Core practice:
> Keep the commitment, renegotiate it early, or repair it honestly.

Owns basic follow-through.

This is why **Follow-through is not a featured V1 Growth Path**.

No daily Habit required.

---

### F12. Live Practically

**Purpose:** Deal with real-world money, admin, decisions and responsibilities.

Core practice:
> Identify the concrete practical move and do the smallest useful next step.

Examples:
- pay bill
- make appointment
- compare options
- send required document
- organise budget

These often belong in Plan rather than Habits.

No daily Habit required.

---

## Tier 5 — Meaning

### F13. Make Meaning

**Purpose:** Connect life to values, beauty, service, purpose and what matters.

Core practice:
> Do one small thing that expresses what matters to you.

No daily Habit required.

# 7. EXACT V1 PATH PRACTICES / RETURNS

## P1. Stillness

**Domain:** Inward

**Quality:** creating a pause before automatic reaction.

**How it shows up:**
> Pause before you react, not only after.

**V1 return:**
> In a moment where you would normally react immediately, pause before responding.

**It counts when:**
> You noticed the impulse and created even a small pause. You do not need to feel calm.

**Daily Habit?**
No Path-owned daily Habit.

Note:
The user may separately have the Regulate Habit "5-minute meditation / settling". Do not duplicate it here.

---

## P2. Self-possession

**Domain:** Inward

**Quality:** remaining yourself around approval, admiration, attraction or social pressure.

**How it shows up:**
> Stay yourself around someone you want to impress.

**V1 return:**
> Say or do one thing that is genuinely yours when you feel tempted to perform, impress, shrink or become what someone else wants.

**It counts when:**
> You chose one authentic action, preference or sentence.

**Daily Habit?**
No.

---

## P3. Non-attachment

**Domain:** Inward

**Quality:** wanting something without making your life contingent on receiving it.

**How it shows up:**
> Want fully. Do not require the outcome.

**V1 return:**
> Name the outcome you are gripping and name what remains yours even if you do not receive it.

**It counts when:**
> Both parts are named. Wanting does not need to disappear.

**Daily Habit?**
No.

Important:
Do not present Non-attachment as suppressing emotion, indifference, "getting over someone", or treatment for limerence.

---

## P4. Resilience

**Domain:** Inward

**Quality:** returning to life while something still hurts.

**How it shows up:**
> Take the next action while it still stings.

**V1 return:**
> After disappointment, rejection, pain or failure, take one small useful next action.

**It counts when:**
> The action happens. The pain does not need to be gone.

**Daily Habit?**
No.

Distinct from Foundation "Handle Hard Things".

---

## P5. Reciprocity

**Domain:** Together

**Quality:** allowing relationships to reveal whether movement flows both ways.

**How it shows up:**
> Notice whether it flows both ways.

**V1 return:**
> Offer once, then stop adding, chasing or compensating long enough to observe whether the other side moves toward you.

**It counts when:**
> You allowed space for reciprocity rather than manufacturing it.

**Daily Habit?**
No.

---

## P6. Emotional Courage

**Domain:** Frontier

**Quality:** allowing honest emotional truth to be visible.

**How it shows up:**
> Say the true thing even when it exposes you.

**V1 return:**
> Allow one genuine feeling, preference, need or truth to be visible without hiding it behind a joke, apology or unnecessary hedge.

**It counts when:**
> The honest thing becomes visible.

**Daily Habit?**
No.

---

## P7. Quiet Authority

**Domain:** Together

**Quality:** calm, unhurried, self-respecting expression.

**How it shows up:**
> Say it once. Do not over-explain.

**V1 return:**
> Say what you mean calmly and resist the urge to produce a long defence after it.

**It counts when:**
> You state it clearly and allow it to stand.

**Daily Habit?**
No.

---

## P8. Warmth

**Domain:** Together

**Quality:** allowing genuine friendliness and care to reach another person.

**How it shows up:**
> People notice that you noticed them.

**V1 return:**
> When genuine warmth arises, express it instead of keeping it inside.

**It counts when:**
> One sincere warm response, acknowledgement or kindness is expressed.

**Daily Habit?**
No.

Important:
Do not create a mandatory "one kindness every day" Habit. Warmth should remain genuine, not a quota.

---

## P9. Seeing People

**Domain:** Together

**Quality:** taking another person in rather than merely waiting to respond.

**How it shows up:**
> Taken in, not just responded to.

**V1 return:**
> Ask the genuine second question and stay with the person's answer.

**It counts when:**
> You remain with their experience instead of immediately turning the conversation back to yourself.

**Daily Habit?**
No.

---

## P10. Grace

**Domain:** Together

**Quality:** strength that preserves dignity.

**How it shows up:**
> Let people keep their dignity.

**V1 return:**
> In a situation where you could punish, embarrass, humiliate, score a point or unnecessarily prove superiority, choose the response that preserves dignity without abandoning your own boundary.

**It counts when:**
> You remain self-respecting without unnecessary cruelty or humiliation.

**Daily Habit?**
No.

Grace must not mean tolerating abuse, surrendering boundaries or being passive.

---

## P11. Curiosity

**Domain:** Frontier

**Quality:** moving toward what is not yet understood.

**How it shows up:**
> Move toward what you do not understand.

**V1 return:**
> Follow one genuine question into something you do not yet understand before immediately judging, dismissing or closing it.

**It counts when:**
> You genuinely investigate, ask, explore or test.

**Daily Habit?**
No.

---

## P12. Agency

**Domain:** Craft

**Quality:** orienting toward available action rather than helplessness.

**How it shows up:**
> Look for the move you can make.

**V1 return:**
> Identify one move that is genuinely under your control and make it.

**It counts when:**
> A real action occurs.

**Daily Habit?**
No.

Important:
"Choose today's priority" belongs to Today / Plan, not as a duplicated Agency Habit.

---

## P13. Shipping

**Domain:** Craft

**Quality:** letting reality respond to something you made.

**How it shows up:**
> Put it in front of people before it feels perfect.

**V1 return:**
> Put something imperfect in front of reality: a user, customer, audience, application, listing, collaborator or other real external feedback source.

**It counts when:**
> The thing leaves private preparation and meets reality.

**Daily Habit?**
No.

Examples:
- share beta
- publish listing
- send application
- show prototype
- launch product page

Do not turn Shipping into a daily quota.

---

## P14. Play

**Domain:** Frontier

**Quality:** aliveness without productivity as the justification.

**How it shows up:**
> For no reason other than it is fun.

**V1 return:**
> Do something because it is enjoyable, absorbing or alive without requiring a productive outcome.

**It counts when:**
> The activity is allowed to be valuable without optimisation.

**Daily Habit?**
No.

# 16. ONBOARDING RULES

V1 onboarding must not overwhelm.

Do NOT:
- activate all 13 Foundations
- activate 3 Paths automatically
- activate all 9 Habits
- show a giant setup checklist

Preferred flow:

1. Explain Compass briefly.
2. Offer one suggested starting journey or allow skip.
3. Offer **one tiny daily Habit**.
4. Enter Today.

For a generic public user:
- avoid assuming limerence
- Stillness may remain the suggested first Path if already used in current onboarding
- user may skip

- See Clearly
- Non-attachment
- Self-possession

Do not hard-code this trio for all users.

Today should remain small.

1. **One deliberate practice / theme**

3. **Daily Habits**

# 18. PATH SPACING RULE

Growth Paths are not daily.

- no shame if a Path is untouched for several days

Habit UI and Path return UI must remain visibly and conceptually different.

# 19. LIMerence-SAFETY PRODUCT RULES

Compass may support behaviours useful when someone experiences obsessive attachment, but it is not a limerence treatment product in V1.

Do not implement:
- "David tracker"
- "days without checking them"
- contact/no-contact streak as a moral score
- obsession frequency score
- "percent healed"
- countdown to recovery
- AI diagnosis of attachment style
- claims that Non-attachment cures limerence

```text
See reality clearly
→ remain yourself
→ allow actual reciprocity to reveal itself
→ tolerate difficult feelings
→ return attention to available action
→ build a larger life
```

This is why the featured set contains:
- Self-possession
- Non-attachment
- Resilience

- Agency
- Shipping
- Curiosity
- Play

# 20. AI CONTENT RULES FOR THESE SYSTEMS

When AI references Foundations / Paths / Habits:

AI may:
- reflect patterns
- suggest one relevant existing practice
- point out a gentle inconsistency
- help phrase an insight
- remind user that a missed day does not erase progress

AI must not:
- diagnose
- invent new V1 Paths
- automatically activate a Path
- automatically prescribe medication/supplements
- claim a user has healed/integrated a Path
- override the self-claimed integration rule
- turn AI advice into a new daily Habit without explicit user action
- expose hidden personal data unnecessarily

Whenever possible, local deterministic logic should decide **whether** an insight is useful; AI should help with interpretation / language.
