Palette

Six hues at the same perceptual lightness and strength, plus a warm stone for foundations and one deep slate for every button, link and selected state. Each hue has three steps: soft for tracks and chips, base for bars, tiles and rings, deep for coloured text.

Rules

  • Buttons, links, selected tabs and Trello ticks are always primary. Colour never decides which button to press.
  • A colour always means the same thing: sleep is blue, rituals are sage, each path area keeps its own hue, foundations are stone.
  • Charts use base for data and soft for the empty track of the same hue, never grey bars next to coloured ones.
  • Coloured text uses deep, so labels stay readable on white.
