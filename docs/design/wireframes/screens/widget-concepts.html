Android widget concepts. These are external triggers — the user sees them without opening the app, creating a re-entry pull. Tap the "Done" circle in Widget A to see the completion state.
Widget A — Daily Anchor
4×2 grid · 320×160dp · Home screen
The primary external trigger. Shows the day’s cue, the sentence you’re practising, and one-tap completion. The lock screen is exactly where you need the sentence — mid-day, mid-task. Tapping the circle marks it done in-app and updates the widget.

Widget B — Where you are on the path
2×2 grid · 160×160dp · Home screen
Quiet identity reinforcement. The ring shows your position across the three camps, and the number below is a plain count of returns — not a streak, so a rest day costs nothing. Tap opens the Paths tab.
