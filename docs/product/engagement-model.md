# Engagement model

Compass is engaging but not manipulative. The mechanisms below are the full list of allowed retention/motivation patterns.

## Core loop

```
Log today → see progress → grow qualities → identity feels real → repeat
```

## Two engines

| Engine | Rhythm | Purpose |
|---|---|---|
| **Rituals (habits)** | Daily, automatic | Stable anchors — morning/evening. Many coexist because they're cheap. |
| **Practice (qualities)** | ~2–4×/week, one per day, rotated | Deliberate growth. Spacing beats daily grind. Never the same quality two days running. |

## Integration states (qualities & tools)

```
Drawn to  →  Practising  →  Integrated  (or Paused)
```

- **Drawn to** — hard cap of 3. Not a wishlist; reframed as "a seed already in you."
- **Practising** — active, shows on Today.
- **Integrated** — self-claimed by the user, never auto-awarded by the app.
- **Paused** — history kept, no pressure.

## 108-rep mastery

Habits track lifetime completions toward a cycle target (21 / 40 / 66 / 108 reps). Default is 108. Progress is purely informational — no punishment for slow pace.

## Gradual build (anti-overwhelm)

- Onboarding starts with **one tiny habit**.
- New habits added one at a time, only when the current one is steady.
- Each habit starts at its smallest dose and escalates gradually.

## Allowed engagement patterns

- Light streaks (shown gently, never weaponised)
- Paths with camps and story progression
- Gentle visual world growth
- Soft rewards for milestones
- Meaningful check-in reflections

## Prohibited patterns

- Leaderboards or global rankings
- Shame or punishment for missed days
- Fake urgency / countdown pressure
- "Fix yourself" or deficit framing
- Addiction-style dark patterns

## Missed-day tone

> "Welcome back. Nothing's lost."  
> Never: "You broke your streak."
