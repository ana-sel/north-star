# Engagement model

> **Guidelines, not rules.** These are the current best answers, not a contract.
> Get the design right first, then update this file to match it.

Compass is engaging but not manipulative. The mechanisms below are the full list of allowed retention/motivation patterns.

## Core loop

```
Log today → see progress → grow qualities → identity feels real → repeat
```

## Two engines

| Engine | Rhythm | Purpose |
|---|---|---|
| **Rituals (habits)** | Daily, automatic | Stable anchors — morning/evening. Many coexist because they're cheap. |
| **Practice (qualities)** | ~2–4×/week, one per day, rotated | Deliberate growth. Spacing beats daily grind. Never the same quality two days running. |

## Integration states (qualities & tools)

```
Drawn to  →  Practising  →  Integrated  (or Paused)
```

- **Drawn to** — hard cap of 3. Not a wishlist; reframed as "a seed already in you."
- **Practising** — active, shows on Today.
- **Integrated** — self-claimed by the user, never auto-awarded by the app.
- **Paused** — history kept, no pressure.

## 108-rep mastery

Habits track lifetime completions toward a cycle target (21 / 40 / 66 / 108 reps). Default is 108. Progress is purely informational — no punishment for slow pace.

## Qualities have no rep target

Rep cycles apply to **habits**, which are daily and countable. A **quality** has no threshold, and inventing one would be false and coercive. Lally et al. (2010) found automaticity anywhere between **18 and 254 repetitions**, averaging ~66 — the spread is the finding.

So Compass states the range, names the variance, and hands the decision back: *"There isn't a number. Compass will never tell you that you've done it. You decide that."*

- Never a bar toward 66, an "N to go" counter, or an integration percentage.
- A plain count of returns so far is fine, shown next to the honest range.
- Camp counters ("4 more practices open Camp 3") are fine — a camp is a real, near, deadline-free step. Integration itself is never counted.

## The quality changes in the inner voice

Two people assemble the same wardrobe for the same hour. One thinks *"I'm hopeless at this — who wrote these instructions?"*, the other *"Huh, interesting how that part fits. I'll find a way."* Same visible behaviour; only the second is practising anything.

Every quality therefore carries a **voice pair** — the automatic sentence and the one being practised. Rules:

- Frame the first as a **state** ("when it's tight"), never a character flaw or a wrong thought.
- Never mark it with an ✗ or red — that is deficit framing.
- The practice is *noticing which voice is speaking*, not eliminating one.

## Every practice needs "it counts when"

A practice that names only a container ("sit for 5 minutes") leaves the user to invent their own success condition — and they will pick the **outcome**, which is never theirs to control. So each practice states an achievable completion condition and explicitly rules out the outcome:

| Practice | It counts when | Explicitly *not* |
|---|---|---|
| The 5-minute sit | you came back once | when your mind goes quiet |
| Take one thing to done | you did the last tenth | when the result is good |
| Say it once, then stop | you stopped after saying it | when they agree |
| Say the kind thing | you said it out loud | when they respond well |
| Do the unfamiliar thing | you started before feeling ready | when it goes well |

This is the difference between a practice that builds someone and one that quietly grades them.

## Gradual build (anti-overwhelm)

- Onboarding starts with **one tiny habit**.
- New habits added one at a time, only when the current one is steady.
- Each habit starts at its smallest dose and escalates gradually.

## Allowed engagement patterns

- Light streaks (shown gently, never weaponised)
- Paths with camps and story progression
- Gentle visual world growth
- Soft rewards for milestones
- Meaningful check-in reflections
- Forward counters toward a real, near, deadline-free milestone ("4 more practices open Camp 3")
- **News that is true**: "You came back twice since you were last here." Only when the count is non-zero, always warm and factual — never `+2`, a badge or a score.
- **No manufactured reveal.** A shimmer-then-slot-machine "Pattern spotted" fired on every tick is a variable-reward mechanic wearing an insight's clothes, and the stat it shows was never earned by that tap. Patterns live on Discover, where they carry evidence and can be disagreed with. The honest reward for practising is the mark landing on your own trail.
- **Done is warmer, not dimmer.** A completed practice must not grey out, fade or strike through. Fading reads as *deactivated*, and a strikethrough says the way of being is finished with — the opposite of the point. Completion earns colour: the tick fills, the day's mark lands, and one true line names the return.

## Visible journey, honest signal

The expedition language (paths, camps, walking, terrain) has to be visible or it's just decoration on a progress bar. The path card draws a **route**: three camp nodes, a gold claim node at the end that only the user fills, and a **walker** positioned by real returns.

The rule that makes it safe: **the walker derives only from completed returns, so it can never move backwards.** A bad week costs nothing already earned. Growth accumulates; it never decays.

## Prohibited patterns

- Leaderboards or global rankings
- Shame or punishment for missed days
- Fake urgency / countdown pressure
- "Fix yourself" or deficit framing
- Addiction-style dark patterns

## Displaying spaced practice

Practice is **deliberately spaced** — 2–4× a week, never two days running — and a skip on Today is
a legitimate choice. Any display that shows the rest days as empty slots turns the design into
visible failure.

- **Never** a daily grid with empty cells, an attendance ratio ("5 of 7 days"), or a days-since counter.
- **Instead** draw only the days the user returned, on a plain line, and say why the gaps are there.
- After a week away the tone stops counting: **"Resting — nothing's lost."**

Rituals (daily habits) are a different rhythm and may be tracked densely — they live in Log · Habits.
A path may carry no ritual at all, and one ritual may be shared by several paths.

## Missed-day tone

> "Welcome back. Nothing's lost."  
> Never: "You broke your streak."
